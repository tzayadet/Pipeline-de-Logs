JSONL Detection Engine

A small rule-based event detector. Feed it JSON Lines, load YAML rules and inspect the alerts produced by matching events.

SAMPLE INPUT

Authentication event

{"event":"authentication_failed","message":"Failed password for test","source_ip":"192.0.2.24"}

This showcase uses a small browser-side example to illustrate keyword matching. It does not run the Python CLI or load the YAML file.

How the prototype works

  • Reads one JSON object per input line from standard input.
  • Loads rule definitions from a YAML file.
  • Applies regular-expression keyword matching to the serialized event.
  • Prints an alert for each matching rule.

Scope: this is an educational prototype, not a SIEM or a complete Sigma implementation. It does not include temporal correlation, event normalization, persistence or alert management.

Static interactive showcase · Synthetic example data · No event is transmitted or stored.
